# Changelog

This changelog distinguishes the application's reconstructed release history from the Git history of this public portfolio repository.

## Portfolio Repository — July 2026

### Added

- Public, portfolio-safe copy of the application source
- Complete recruiter-facing README
- Safe example hosting configuration
- Engineering case study
- Retrospective development history
- Engineering roadmap

### Excluded for privacy and operational safety

- Production database content
- Uploaded attendance or supporting files
- Saved Executive Board comments
- Production project identifier
- Operational editing URL

## Application Release — July 2026

### Reporting workflow

- Created a shared tracker for 100 report rows derived from 53 base activity IDs
- Added Full Year, Fall 2026, and Spring 2027 progress views
- Added month, week, status, programming-lane, and undated views
- Added **Not Started**, **Gathering Information**, and **Submitted** states
- Added direct status controls and visible save feedback

### Data and classification

- Preserved 95 dated occurrences and 5 undated activities
- Added six programming lanes and related subcategories
- Added source-issue flags for missing or conflicting information
- Added repeatable **fit first, balance second** classification guidance
- Supported repeated lane and subcategory changes with refreshed counts

### Event and Board workflows

- Added editable event-details forms
- Added the dedicated **Executive Board Comments** workspace
- Added named and editable comments
- Added multiple attachments per event and comment
- Added previews, single deletion, and multi-select deletion
- Added comment counts to report views

### Interface and navigation

- Added responsive desktop, tablet, and mobile layouts
- Added collapsible navigation and compact semester controls
- Added search, filters, clear filters, and stable sorting
- Added clickable dashboard summaries
- Added route persistence and browser back/forward behavior
- Prevented automatic opening of a single filtered report
- Removed the dashboard flash during route restoration

### Storage and reliability

- Added D1-compatible shared event persistence
- Added R2-compatible supporting-file storage
- Added freshness metadata and conflict-aware record merging
- Added seed-data fallback
- Added a 20 MB per-file upload limit

### Documentation and handoff

- Standardized the product name as **Monthly Activity Report**
- Added an Executive Board user guide
- Added development handoff and continuity guidance
- Documented that tracker status does not prove submission to the national NSBE form
